# Security Policy

## Supported Versions

We release patches for security vulnerabilities. Currently supported versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's security advisory feature:

1. Go to the Security tab
2. Click on "Report a vulnerability"
3. Fill out the vulnerability details

We will respond to security reports within 48 hours and provide regular updates on the resolution progress.

**Do not** open public issues for security vulnerabilities.

## Security Measures

This repository has the following security features enabled:
- Dependabot security updates
- CodeQL code scanning
- Secret scanning with push protection
- Branch protection with signed commits
- Required pull request reviews
